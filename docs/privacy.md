# Privacy

Office Desk has no account, backend, analytics, cookies, ads, or cloud sync. Countdown configurations, notes, checklist items, and preferences are stored in this browser on this device. Clearing browser site data removes that information.

Custom countdown background images are resized in the browser and stored with the countdown on this device. The Share Countdown action creates a URL with the selected countdown settings; it does not include custom images or other saved content. Anyone with that URL can read its included title, subtitle, target instant, timezone label, event type, theme, reference date, completion behavior, celebration level, and sound preference.

The hosted app downloads its static files from GitHub Pages. Once cached, the app shell works offline. No user-entered tool content is sent to a server.
