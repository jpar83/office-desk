# User guide

## Countdowns

Create a countdown, choose a milestone type and visual theme, and select its target date and time. Choose a primary countdown to feature on Home. Full screen is useful for a shared display. Share creates a link with that countdown’s configuration; a recipient can preview it temporarily or save it on their device.

## Timers and helpers

Timer offers a duration, count-up, and end-at-time mode. Meeting adds agenda segments. Focus provides focus and break phases. Notes and checklist autosave locally. Text tools transform text in the browser. Date math treats weekdays as Monday through Friday and does not account for holidays. Percentage tools label their formulas. QR codes are generated on-device.

## Settings

Choose light, dark, or system appearance, then use Color Studio to pick Quiet Sage, Coastal Blue, Orchid, Terracotta, Rosewater, or Graphite. Fine-tune 14 colors independently for light and dark mode; the preview updates immediately and saves only in this browser. Contrast checks flag combinations below the WCAG AA 4.5:1 text target. The countdown’s six illustrated event themes remain separate from the app-wide palette. Reset the current color set to the Office Desk defaults at any time. Reset data permanently clears Office Desk’s locally stored content in this browser.
